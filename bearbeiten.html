Speichern: so kommen die Änderungen auf die Website

Die Änderungen liegen bis jetzt nur in diesem Fenster. Für die Website müssen sie in die Datei inhalt.yaml – das geht in drei Schritten:

  1. Text kopieren

    Ein Klick genügt, der gesamte Inhalt landet in der Zwischenablage.

  2. Bei GitHub einfügen

    Der Knopf öffnet die Datei inhalt.yaml in einem neuen Fenster. Dort im Textfeld alles markieren (Strg + A, am Mac ⌘ + A) und mit Strg + V (⌘ + V) den kopierten Text einfügen.

    inhalt.yaml bei GitHub öffnen ↗

  3. Änderung vorschlagen

    Oben rechts auf „Commit changes…“ klicken, im Fenster „Create a new branch for this commit and start a pull request“ auswählen und mit „Propose changes“ bestätigen. Danach entsteht automatisch eine Vorschau-Seite zum Anschauen, und die Änderung kann übernommen werden.

Kein GitHub zur Hand? Datei herunterladen und verschicken

Die Datei speichern und per E-Mail schicken – der Rest passiert dann am anderen Rechner.
